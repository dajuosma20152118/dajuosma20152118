# Skills de Claude

Pack de 11 skills **Replica** para Claude Code (licencia MIT, © 2026 Jake Schincariol; cada carpeta incluye su `LICENSE`).

| Skill | Para qué sirve |
|---|---|
| `replica-recon` | Analiza una app y saca el mapa de pantallas, flujos, modelo de datos y matriz de funciones |
| `replica-architect` | Elige stack, escribe el esquema de base de datos y planifica la API |
| `replica-design` | Reconstruye el sistema de diseño (tokens, componentes) y comprueba contraste |
| `replica-build` | Construye la app pantalla a pantalla |
| `replica-backend` | Auth, base de datos, pagos con Stripe, email, integraciones |
| `replica-test` | Plan de pruebas, tests e2e con Playwright y reportes de bugs |
| `replica-diff` | Mide cuánto se parece al original y qué falta |
| `replica-entrepreneur` | Lee reseñas reales de usuarios y propone mejoras y posicionamiento |
| `replica-brand` | Nombre, paleta, logo y voz propios; busca restos del original |
| `replica-launch` | Landing, precios y fichas de App Store / Google Play |
| `replica-deploy` | Puesta en producción con dominio propio |

## Instalación

```bash
git clone https://github.com/dajuosma20152118/dajuosma20152118.git
mkdir -p ~/.claude/skills
cp -r dajuosma20152118/skills/replica-* ~/.claude/skills/
```

Abre una sesión nueva de Claude Code para que aparezcan.
